# 취업준비 스킬 라우팅

현재 요청의 핵심 결정을 담당하는 가장 좁은 스킬을 선택한다. 이미 완료한 경험 발굴을 다른 스킬에서 반복하지 않는다.

| 주관팀 | 요청 | 사용할 스킬 | 산출물 | 사용하지 않을 때 |
|---|---|---|---|---|
| PM팀 | 프로젝트의 실제 사건·판단·기여를 발굴하거나 직무 관점에서 재해석 | `pm-experience-mentor` | 제약·판단·행동·성과가 연결된 경험 스토리 | 확정된 글의 단순 교정만 필요할 때 |
| 커리어 컨설턴트팀 | 선택한 경험을 특정 공고·문항에 맞는 자소서로 발전 | `pm-drama-upgrade-mentor` | 공고 해석, 차별화 주장, 집중 질문, 첨삭·평가 | 경험 근거가 전혀 복원되지 않았을 때 |
| 커리어 컨설턴트팀 | 여러 공고의 반복 역량과 포지셔닝 변화를 분석 | `job-posting-signal-analyzer` | 기본 시그널 또는 주간 변화, 증명 가능 역량과 갭 | 단일 회사 자소서 작성이 목적일 때 |

## 공고 시그널에서 지원서까지

1. `job-posting-signal-analyzer`로 반복 요구역량과 근거 갭을 찾는다.
2. 증거가 부족하면 `pm-experience-mentor`로 관련 경험을 복원한다.
3. `pm-drama-upgrade-mentor`로 목표 공고의 채용 논리에 맞춰 최종 서사를 만든다.

## 기존 초안의 주장이 약할 때

1. 경험 사실이 충분하면 `pm-drama-upgrade-mentor`에서 시작한다.
2. 실제 기여가 숨겨졌거나 모호하면 필요한 부분만 `pm-experience-mentor`로 확인한 뒤 돌아온다.

## 주간 공고 분석

1. `job-posting-signal-analyzer`로 신규·실질 변경 공고만 읽는다.
2. 기존 시그널과 달라진 내용 및 포지셔닝 조치만 보고한다.
3. 지원서·이력서를 자동으로 고치지 않고 명시적인 후속 요청을 해당 스킬로 라우팅한다.

## 스킬이 필요 없는 요청

단순 사실 답변, 파일 작업, 맞춤법 수정 또는 경험·시장·지원전략 판단이 필요 없는 문구 수정은 직접 처리한다.
