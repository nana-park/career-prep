# 취업준비 스킬 라우팅

현재 요청의 핵심 결정을 담당하는 가장 좁은 스킬을 선택한다. 이미 완료한 경험 발굴을 다른 스킬에서 반복하지 않는다.

| 주관팀 | 요청 | 사용할 스킬 | 산출물 | 사용하지 않을 때 |
|---|---|---|---|---|
| PM팀 | 프로젝트의 실제 사건·판단·기여를 발굴하거나 직무 관점에서 재해석 | `pm-experience-mentor` | 제약·판단·행동·성과가 연결된 경험 스토리 | 확정된 글의 단순 교정만 필요할 때 |
| 커리어 컨설턴트팀 | 선택한 경험을 특정 공고·문항에 맞는 자소서로 발전 | `pm-drama-upgrade-mentor` | 공고 해석, 차별화 주장, 집중 질문, 첨삭·평가 | 경험 근거가 전혀 복원되지 않았을 때 |
| 커리어 컨설턴트팀 | 여러 공고의 반복 역량과 포지셔닝 변화를 분석 | `job-posting-signal-analyzer` | 기본 시그널 또는 주간 변화, 증명 가능 역량과 갭 | 단일 회사 자소서 작성이 목적일 때 |
| 커리어 컨설턴트팀 | 기본 이력서·경력기술서를 관리하거나 공고별 제출본으로 파생 | `resume-career-document-editor` | 기준본·파생본 구분, 정합성 점검, 공고별 정보 위계와 버전 기록 | 새로운 경험을 발굴하거나 단일 자기소개서 문항을 작성할 때 |
| 커리어 컨설턴트팀 | 면접 질문 준비도를 점검하거나 답변·꼬리질문을 리허설 | `interview-strategy-coach` | 질문별 준비 상태, 근거 경험, 취약한 반문, 보강 우선순위 | 서류 문구 편집만 필요하거나 경험 사실이 전혀 복원되지 않았을 때 |
| 커리어 컨설턴트팀 | 포트폴리오 사례를 고르거나 목차·페이지·시각 자료 전략을 설계 | `portfolio-strategy-builder` | 사례별 증명 역량, 서사 구조, 필요한 원본·목업과 제작 브리프 | Figma 화면의 시각적 제작만 필요하거나 경험 사실이 전혀 복원되지 않았을 때 |

## 공고 시그널에서 지원서까지

1. `job-posting-signal-analyzer`로 반복 요구역량과 근거 갭을 찾는다.
2. 증거가 부족하면 `pm-experience-mentor`로 관련 경험을 복원한다.
3. `pm-drama-upgrade-mentor`로 목표 공고의 채용 논리에 맞춰 최종 서사를 만든다.
4. `resume-career-document-editor`로 기본서류의 강조점과 제출 버전을 정리한다.
5. `interview-strategy-coach`로 서류의 핵심 주장을 질문과 꼬리질문에서 검증한다.

## 면접 준비와 결과 환류

1. 공통 질문은행과 목표 공고를 기준으로 질문별 준비 상태를 점검한다.
2. 핵심 경험이나 본인 기여가 비어 있으면 필요한 부분만 `pm-experience-mentor`로 보낸다.
3. `interview-strategy-coach`로 답변과 꼬리질문을 리허설하고 합격 리스크를 기록한다.
4. 사실 충돌이나 더 정확한 표현이 발견되면 `resume-career-document-editor`의 기준본에 반영할지 검토한다.

## 포트폴리오 기획과 제작

1. 목표 공고의 평가 기준과 포트폴리오가 증명할 핵심 포지셔닝을 정한다.
2. 경험 인덱스에서 후보를 찾고 관련 Drive 파일 원본으로 사실과 산출물을 검증한다.
3. `portfolio-strategy-builder`로 사례별 증명 역할, 목차와 시각 자료 계획을 만든다.
4. 목업·Figma 작업에는 주장, 원본 범위, 익명화 방식과 완료 기준이 포함된 제작 브리프를 전달한다.
5. 완성본이 기본서류의 사실과 일치하며 면접의 꼬리질문에 대응 가능한지 검수한다.

## 기존 초안의 주장이 약할 때

1. 경험 사실이 충분하면 `pm-drama-upgrade-mentor`에서 시작한다.
2. 실제 기여가 숨겨졌거나 모호하면 필요한 부분만 `pm-experience-mentor`로 확인한 뒤 돌아온다.

## 주간 공고 분석

1. `job-posting-signal-analyzer`로 신규·실질 변경 공고만 읽는다.
2. 기존 시그널과 달라진 내용 및 포지셔닝 조치만 보고한다.
3. 지원서·이력서를 자동으로 고치지 않고 명시적인 후속 요청을 해당 스킬로 라우팅한다.

## 스킬이 필요 없는 요청

단순 사실 답변, 파일 작업, 맞춤법 수정 또는 경험·시장·지원전략 판단이 필요 없는 문구 수정은 직접 처리한다.
