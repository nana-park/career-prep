# 경험 소스 조회 규칙

경험을 지원서, 기본서류, 포트폴리오 또는 면접 답변에 사용할 때는 Google Drive의 경험 인덱스와 파일 원본을 역할에 맞게 조회한다.

## 소스 우선순위

1. `experience_index`에서 현재 요청과 관련된 경험 후보를 찾는다.
2. 선택한 경험의 링크와 단서를 따라 `experience_originals`의 파일 원본을 확인한다.
3. 원본에서 확인되지 않은 수치, 기간, 역할, 의사결정 권한과 기술 요소는 확정 사실로 쓰지 않는다.

`experience_index`는 탐색을 빠르게 하는 요약·분류 소스이고, 최종 사실 원장은 파일 원본이다. 둘이 충돌하면 원본을 우선하되, 원본 간에도 값이 다르면 임의로 합치지 않고 사용자에게 확인한다.

## 언제 읽는가

- 사용자가 자신의 경험, 경력, 프로젝트 또는 포트폴리오 사례를 묻는 경우
- 공고의 요구역량을 증명할 실제 사례를 선택하는 경우
- 이력서·경력기술서·자기소개서·면접 답변의 사실을 검증하는 경우
- 기존 경험 요약에 없는 기술 제약, 판단 과정, 성과 근거 또는 산출물이 필요한 경우

단순 문구 교정이나 이미 확인된 사실만 사용하는 후속 작업에서는 매번 전체 Drive를 다시 읽지 않는다. 필요한 경험과 관련 파일만 선택적으로 조회한다.

## 공개 저장소 경계

실제 Drive URL, 파일 원문, 회사 내부 정보와 개인정보는 이 저장소에 기록하지 않는다. 공개 문서에는 소스의 역할과 조회 규칙만 남기고 실제 연결값은 `sources.local.yaml`에서 관리한다.
