# 주간 채용전략 리뷰

매주 월요일 지난 7일의 지원 결과와 신규 공고 시그널을 함께 검토해 다음 7일의 취업준비 전략을 정한다.

## 입력

- Notion 지원현황과 서류전형 일정의 합격·탈락·대기 및 단계 변경
- 멈춘 지원 건, 누락된 다음 행동과 가까운 마감
- 최근 7일의 신규·실질 변경 공고
- 필요한 경우에만 확인하는 Google Drive의 경험 원본

## 판단 방식

1. `application-pipeline-manager`로 최근 결과와 파이프라인 이상 상태를 확인한다.
2. 결과를 확인된 사실, 반복 패턴과 검증할 가설로 구분한다.
3. `job-posting-signal-analyzer`로 신규 공고의 요구역량 변화를 확인한다.
4. 실제 결과와 시장 시그널을 교차해 다음 주의 지원·서류·포트폴리오·면접 전략을 정한다.

표본이 적거나 탈락 사유가 확인되지 않으면 원인을 단정하지 않는다. 의미 있는 변화가 있을 때만 전략을 바꾸고, 다음 주에 검증 가능한 조치 1~3개와 완료 기준을 제시한다.

## 변경 권한

주간 리뷰는 Notion, Drive와 제출 문서를 자동 수정하지 않는다. 실제 데이터 또는 산출물 변경은 사용자의 명시적 요청을 받아 해당 팀원이 수행한다.
