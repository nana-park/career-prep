# 하루 업무 마감

## 실행 조건

사용자가 현재 취업준비 업무를 그날 종료하겠다는 의사를 자연어로 명확히 밝히면 실행한다. `오늘 그만하자`, `오늘은 여기까지`, `나머지는 내일 하자`, `이제 마무리하자` 등이 예시이며 정확한 문구 일치를 요구하지 않는다.

표현을 예시로 들거나 기능을 설명하거나 미래의 종료 계획을 말한 경우에는 실행하지 않는다. 현재 세션을 실제로 마치려는 의도를 문맥으로 판단한다.

## 처리 방식

1. 오늘 대화와 확인 가능한 작업 상태에서 완료한 일을 정리한다.
2. 미완료 작업, 막힌 이유와 외부 대기사항을 구분한다.
3. 다음 날로 넘길 작업을 중요도와 마감 기준으로 정한다.
4. 필요한 경우 다음 날 Google Calendar의 busy 시간과 Notion 일정·지원 현황을 확인한다.
5. 내일 시작할 첫 행동을 하나로 구체화한다.
6. 비민감 이월 요약을 `private/daily-close-state.json`에 기록한다.

## 마감 보고 형식

- 오늘 완료
- 미완료·보류와 이유
- 내일 이월 작업
- 내일 첫 행동
- 가까운 마감 또는 일정 충돌

사용자의 명시적 요청 없이 Google Calendar 이벤트, Notion 항목, Drive 원본을 생성하거나 수정하지 않는다. 개인 일정 상세, 지원서 원문, 비공개 링크와 회사 내부 정보는 로컬 상태에도 저장하지 않는다.
